# Cortex Cloud XQL Samples

A knowledgebase of sample XQL queries for Cortex Cloud (Palo Alto Networks), organized by dataset.

## Datasets

| Dataset | Description |
|---------|-------------|
| [asset_inventory](datasets/asset_inventory.md) | Normalized inventory of all digital assets across cloud environments |
| [cloud_health_auditing](datasets/cloud_health_auditing.md) | Health and error events for scanning capabilities |
| [cloud_audit_logs](datasets/cloud_audit_logs.md) | Cloud provider API audit logs |
| [cwp_packages_raw](datasets/cwp_packages_raw.md) | Raw package data from workload protection scans |
| [findings](datasets/findings.md) | Security findings across all finding types |
| [uvm_findings](datasets/uvm_findings.md) | Vulnerability-specific findings |
| [issues](datasets/issues.md) | Cortex Cloud issues |
| [cases](datasets/cases.md) | Cases aggregating related issues |
| [case_to_issue](datasets/case_to_issue.md) | Mapping between cases and issues |
| [cas_criteria](datasets/cas_criteria.md) | CAS policy criteria |
| [cas_policies](datasets/cas_policies.md) | CAS policies |
| [ciem_permissions_with_last_access](datasets/ciem_permissions_with_last_access.md) | Cloud identity permissions with last access metadata |
