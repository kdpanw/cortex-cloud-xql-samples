# uvm_findings

## Overview

Specialized dataset specifically for vulnerability findings from Unified Vulnerability Management (UVM). Provides richer vulnerability-specific fields compared to the general `findings` dataset.

**Use when you need to:**
- Query vulnerability findings with more granular UVM-specific fields
- Prioritize vulnerabilities by severity, CVSS score, or exploitability
- Report on vulnerability remediation status
